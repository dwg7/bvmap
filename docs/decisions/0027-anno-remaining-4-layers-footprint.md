# 0027: 注記(Anno)の残り4層、踏み跡調査

[0017](0017-category-table-generator-stage1.md)以来保留にしていた「let包装パターン」を含む、注記の残り4層(`bvmap-注記シンボル付き重なり`・`bvmap-注記道路番号`・`bvmap-注記シンボル付きソート順100以上`・`bvmap-注記シンボル付きソート順100未満`)を実データで調査した。まだ実装はしていない。

## `bvmap-注記シンボル付き重なり`: 純粋な一回性アイコン層

vt_code `[5801,6341,7601,7621]`(滝・史跡名勝天然記念物・砂礫地・雨裂)専用のアイコンレイヤー。テキスト・色を一切持たない(`icon-opacity`のみ)。他レイヤーと共有するテーブルは無い、確定的な一回性レイヤー。

filterに`vt_flag17`によるzoom16/17の段階的ステップが使われている——[0025](0025-remaining-post-tier-13-layers-footprint.md)で確認した「z17詳細化フラグ」が、道路・鉄道だけでなく**注記(Anno)にも及ぶ、本当に横断的な仕組み**であることが確認できた(3つ目の適用領域)。

## `bvmap-注記道路番号`: 実は単純な2分岐match

paintは`text-color`1つだけで、中身は`["match",["get","vt_code"],7701,"rgba(0,0,0,1)","rgba(255,255,255,1)"]`——vt_code 7701(水面標高)だけ黒、それ以外(2901国道番号/2903都市高速道路番号/2904高速道路番号)は白。**当初「共有パターン無し」と分類していたが、実際には`compile_match_expression()`でそのまま再現できる、ただ規模が小さいだけの通常のflat_matchだった**。

## `bvmap-注記シンボル付きソート順100以上/100未満`: let包装パターンの正体が判明

[0017](0017-category-table-generator-stage1.md)で「未検証」としていたものを実データで解明した。構造は:

```
["let", "color",
  <Anno text-colorの共有ランプ(0008/0017)そのもの、category_table.pyのANNO_TEXT_COLOR_CATEGORIES/VALUESとbyte-exactに一致することを確認済み>,
  ["step", ["zoom"],
    ["match", ["get","vt_code"], <ZOOM14未満で消すvt_code集合>, transparent, ["var","color"]],
    14,
    ["match", ["get","vt_code"], <ZOOM14以上で消すvt_code集合>, transparent, ["var","color"]]
  ]
]
```

つまり**「共有ランプの色をそのまま使うが、特定のvt_codeだけズーム帯によって透明にする」**という、共有ランプの上に乗る追加のオーバーレイ。2レイヤー間の「わずかな差分」の正体は、透明にする対象vt_code集合そのもの:

| | zoom<14で透明 | zoom≥14で透明 |
|---|---|---|
| シンボル付き100以上 | `[661, 662]` | `[3201,3204,3215,3216,3217,3218,3243]` |
| シンボル付き100未満 | `[631,632,633,6368,6376]` | `[3212,3213,3214]` |

[0008](0008-cartographic-layer-ordering.md)で見つけた「text-sizeのズーム14で特定vt_codeだけ1.3倍にする」という疎な例外と**同じ形**(ズーム14を境にした、レイヤーごとに異なるvt_code集合への疎な上書き)——予想通りの類似パターンだったと確認できた。

## 実装方針(まだ着手していない)

- `bvmap-注記道路番号`: 新しいカテゴリ(`flat_match`、2分岐)を追加するだけで即再現可能
- `bvmap-注記シンボル付きソート順100以上/100未満`: 共有ランプ(既存の`categories.anno_text_color`)を再利用し、その上に「ズーム14前後で指定vt_codeを透明にする」という新しい小さな構造を被せる関数が要る——`road_color.py`等と同じく「構造はコード、値(どのvt_codeを消すか)はYAML」の形にできそう
- `bvmap-注記シンボル付き重なり`: 一回性、[0009](0009-generator-architecture-direction.md)の「逃げ場」原則通りリテラル保持で良い

これで注記(Anno)9層全ての踏み跡調査が完了した——実装が必要なのは2層(道路番号は既存の仕組みの流用、シンボル付き100以上/未満は新しい小さな構造)のみ。
