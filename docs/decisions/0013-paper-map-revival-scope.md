# 0013: 紙地図文化復活の範囲(ケース・カンファレンスの結論、ケース5)

## 結論

**GSI公式デジタル版(`optimal_bvmap/style/std.json`)の範囲のまま維持する**。水域・海岸の一部([0010](0010-color-semantic-categories.md)で確認した`vt_code` 321,322,341,342,344,345,347,820,840,841,842等)だけを明朝体とし、山岳・島・その他自然地形への拡張は今回は行わない。

## 検討した拡張範囲(参考、今回は不採用)

紙地図の慣習(2万5千分1地形図図式 第73条、[0008](0008-cartographic-layer-ordering.md))は「自然地形全般=傾斜体」というもっと広い区分を持つ。GSIの地物コード表で該当する`vt_code`を洗い出した:

- 山岳: 311(山の総称)、312(山・岳・峰等)、313(尖峰・丘・塚等)、314/315/316(標高別)、333(山脈・山地・平原)
- 海岸・半島: 323、342、343、346、347
- 海: 341、344、345、348
- 島: 351(総称)、352(島)、353(岩礁等)
- その他自然地形: 331・332(高原・原・森・林・砂丘・湿原)

[0012](0012-italic-axis-abandoned.md)で斜体という軸自体を諦めたため、仮に拡張する場合は書体・ウェイト・色・サイズによる区別になる。
