# 0014: スプライト一括の結論(ケース・カンファレンスの結論、ケース6)

## 結論(3点)

1. **未使用39個は無視する**。119アイコン中、実際に使われているのは80個のみ(前回セッションで確認済み)。未使用分(大半が高ズーム詳細用の「-20」バリアント)は、将来必要になった時点で改めて確認する
2. **絵文字代替は採用しない**。温泉♨️・神社⛩️・郵便局🏣等、GSI記号と一致度の高い候補が16個あったが、絵文字はフルカラーで再配色不可能なため、Starlightの低彩度パレットと矛盾する。作業量削減よりパレットの一貫性を優先する
3. **独自SDFスプライトシートの作成は今回見送る**。作業量が最大の項目であり、フォント・色のケースカンファレンス(方針)が固まってから着手する方が安全

## 未解決のまま残る事実(将来の着手時に参照)

- GSIの119アイコンは全て`sdf: false`(フルカラーPNG)。`icon-color`等での再配色は原理的に不可能
- `@2x`のpixelRatioバリアントが無く、高DPI環境でぼやける
- 複数スプライトソースの合成はMapLibre v3.0から利用可能(`sprite: [{id,url},...]`)。GSIのシートを残したまま独自SDFシートを追加できる
- ネイティブSVGシンボル対応は近い将来実装される兆候が薄い(2022年開始の議論、約4年でコメント5件)
- 素材候補: Mapbox Maki(CC0、JP専用バリアントあり)、GSI公式「外国人にわかりやすい地図記号」(ライセンス未確認)
- ビルドツール: `spreet`(SVG→SDFアトラス、現役)
- 独立したバグ: `bvmap-水部表記線point`(流水方向アイコン)の`icon-size`が固定値でズーム補間されていない。これはスプライト作り直しとは無関係に、いつでも直せる
